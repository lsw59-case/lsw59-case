LDL cholesterol vs. systolic blood pressure, by sex (hover for values)
  • About this dashboard
  • Systolic BP by LDL category
  • Who is in the sample

Question. Among U.S. adults aged 45-79, is a higher LDL cholesterol level associated with higher blood pressure, and does that association differ between men and women or across racial and ethnic groups?

Audience. Students, clinicians, and public-health readers who want a quick, data-grounded look at how two major cardiovascular risk factors relate to each other.

How to use it. Start with the headline numbers above. Explore lets you filter the data yourself. Compare means and Compare proportions hold the formal tests. Sex & ethnicity answers the main question. Data documents every variable.

Data. NHANES 2017-March 2020 pre-pandemic files, retrieved 2026-09-28. Dashboard last rendered 2026-09-28 18:30 EDT.

Summary of the filtered sample 
{
  const groups = {
    sex:      ["Male", "Female"],
    race_eth: ["NH White", "NH Black", "Hispanic", "NH Asian", "Other/Multiracial"]
  }

  const data = transpose(nh_raw).filter(d =>
    sexes.includes(d.sex) && races.includes(d.race_eth) &&
    d.age >= ageMin && d.age <= ageMax)

  // Pearson correlation (JavaScript has no built-in cor())
  const pearson = (x, y) => {
    const n = x.length
    if (n < 3) return NaN
    const mx = d3.mean(x), my = d3.mean(y)
    let sxy = 0, sxx = 0, syy = 0
    for (let i = 0; i < n; i++) {
      const dx = x[i] - mx, dy = y[i] - my
      sxy += dx * dy; sxx += dx * dx; syy += dy * dy
    }
    return sxy / Math.sqrt(sxx * syy)
  }

  const summarize = (rows, label) => ({
    Group: label,
    n: rows.length,
    "Mean LDL (mg/dL)": d3.mean(rows, d => d.ldl),
    "Mean BP (mm Hg)":  d3.mean(rows, d => d[outcome]),
    "Correlation r":    pearson(rows.map(d => d.ldl), rows.map(d => d[outcome]))
  })

  const rows = [
    ...groups[colorBy]
      .map(level => summarize(data.filter(d => d[colorBy] === level), level))
      .filter(row => row.n > 0),
    summarize(data, "All selected")
  ]

  return Inputs.table(rows, {
    format: {
      "Mean LDL (mg/dL)": x => x?.toFixed(1),
      "Mean BP (mm Hg)":  x => x?.toFixed(1),
      "Correlation r":    x => Number.isNaN(x) ? "-" : x.toFixed(2)
    },
    rows: 8
  })
}

Answer to the main question

Across all adults, adjusting for age, sex, and race/ethnicity, each 10 mg/dL higher LDL goes with a 0.36 (90% CI: 0.18 to 0.54) mm Hg difference in mean systolic BP. The interval lies entirely above zero.

Does the slope differ by sex? Interaction test: F = 3.44, p = 0.064.

Does it differ by race/ethnicity? Interaction test: F = 0.79, p = 0.530.

Stratum estimates rest on smaller samples (see table below), so their intervals are wider; read them together with the interaction tests.

About the data

Source. National Health and Nutrition Examination Survey, 2017-March 2020 pre-pandemic files: P_DEMO (demographics), P_TRIGLY (LDL; measured only in the morning fasting subsample), and P_BPXO (oscillometric blood pressure). Retrieved with the nhanesA package on 2026-09-28; analysis data prepared 2026-09-28.

Caveats. Survey weights are not used, so results describe this sample, not the U.S. population. Data are cross-sectional, and medication use (statins, blood pressure drugs) is not accounted for.

Accessibility. Color palettes are safe for common color-vision deficiencies, every static chart has alt text, and the layout reflows on phones and tablets.
